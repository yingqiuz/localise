.. _prepare:

Prepare your data
=================

In this section, we guide you through the process of generating connectivity features, 
which are essential for localising surgical targets using our toolbox.

- :ref:`prerequisites`
- :ref:`estimate-fiber`
- :ref:`create-anatomical-masks`
- :ref:`tract`

.. _prerequisites:

Prerequisites
-------------

* **FSL Installation:** Before proceeding, make sure you've installed 
  `FSL <https://fsl.fmrib.ox.ac.uk/fsl/fslwiki/>`_ first.
* **Required Data**: You'll need both T1 and pre-processed diffusion MRI.
* **Data Organisation:** If you're working with multiple subjects (where each subject has its own folder), 
  ensure that you organise the files for each subject consistently. 
  This will simplify the process moving forward.

.. _estimate-fiber:

Estimate fiber orientations
---------------------------

You first need to resolve fiber orientations required for tractography. 
You need to run FSL's `bedpostx <https://fsl.fmrib.ox.ac.uk/fsl/fslwiki/FDT/UserGuide#BEDPOSTX>`_
on your diffusion data. For a detailed understanding and any troubleshooting, refer to the
`BEDPOSTX UserGuide <https://fsl.fmrib.ox.ac.uk/fsl/fslwiki/FDT/UserGuide#BEDPOSTX>`_.

.. _create-anatomical-masks:

Create anatomical masks
-----------------------

To create anatomical masks for a specific subject (for example, ``subj0001``), 
you can use the following command:

.. code-block:: bash

    create_masks --ref=/path/to/subj0001/t1.nii.gz --warp=/path/to/subj0001/warp.nii.gz --out=/path/to/subj0001/roi --aparc=/path/to/subj0001/aparc.a2009s+aseg.nii.gz

Here's a breakdown of the arguments:

* ``--ref``: The reference T1 image.
* ``--warpz``: The warp field that maps MNI 1mm standard space to the reference T1 space.
* ``--aparc``: The cortical parcellation file ``aparc.a2009s+aseg.nii.gz`` generated by `Freesurfer <https://www.freesurfer.net>`_.
* ``--out``: The directory where the anatomical masks will be saved. 
  If the directory doesn't exist, it will be created. 
  In the provided example, the masks would be saved in ``/path/to/subj0001/roi``.

For additional details and instructions, run ``create_masks --help``.

After running this command, anatomical masks required to run tractography and subsequent
analysis for both hemisphere will be created under the output directory you specified, 
for example, ``/path/to/subj0001/roi/left`` and ``/path/to/subj0001/roi/right``.

.. _tract:

Generate tract-density maps
---------------------------

To create tract-density maps (connectivity features), 
you can run the following command (for example, for subject0001, left hemisphere):

.. code-block:: bash

    create_tracts --samples=/path/to/subj0001/data.bedpostX --inputdir=/path/to/subj0001/roi/left --seed=/path/to/subj0001/seed.nii.gz --out=/path/to/subj0001/my_output_dir

Here's a breakdown of the arguments:

* ``--samples``: The folder containing ``merged_*samples.nii.gz`` samples, 
  e.g., the output directory from FSL's BedpostX.
* ``--inputdir``: The directory that stores anatomical masks.
* ``--seed``: The seed mask for tractography.
* ``--out``: he directory where the tract-density maps will be stored.

For additional details and instructions, run ``create_tracts --help``.
